# 索引

本目录是 `sensor-node-fw`（STM32F103RCT6 + QP/C 的传感器节点固件骨架）的工程文档集。内容以仓库内实际代码与工程配置为准，代码变更时请同步更新对应文档。

仓库根目录 `README.md` 是面向首次进入项目人员的快速入口；需要深入了解架构、接口和验证约束时，再按下面的文档顺序阅读。

## 维护约定

- 每篇顶部有 frontmatter：`status`、`owner`、`updated`
- 引脚名、信号名、函数名统一用反引号包裹，便于全局搜索
- 框架图、状态机图、时序图全部用 Mermaid 代码块，跟随代码一起提交
- 每次改代码，顺手更新对应文档的 `updated` 字段
- **每次有意义的改动，必须在同一次改动里往 [[08-改动日志]] 追加条目**（字段与格式见 [[AGENTS#9. 改动日志]]），不允许事后补记

> [!warning] 尚未覆盖的内容
> 目前没有 Bootloader / OTA、产测与版本配套表的文档，因为代码里还没有对应实现（见 [[01-项目介绍#待办]]）。
> **参数存储已经落地**（2026-09-27，I2C EEPROM / AT24C04）：记录格式见 `sensor-node-fw/App/service/svc_param.h`，
> 运行行为见 [[05-任务说明#AO_Store]]，调试口用法见 [[06-协议格式#参数存储（EEPROM）]]；尚无独立的 NVM 布局专章。
> 业务侧的参数清单已单独立稿（[[10-4G业务参数清单]]，状态为草稿、待实现），其落盘部分仍缺。

## 工具与约束

- [[AGENTS]]（工作区根目录 `AGENTS.md`）：所有 AI / 自动化改动的约束入口，**动手前先读**
- `sensor-node-fw/App/tools/apply_qp_to_keil.ps1`：CubeMX 重新生成后补回 Keil 工程的文件组、预定义宏、头文件路径（幂等，可重复运行）
- `sensor-node-fw/App/tools/smoke_build.ps1`：没有 Keil 时的全量编译 + 链接烟测（arm-none-eabi-gcc），输出 Flash/RAM 占用
- `sensor-node-fw/App/tools/at_smoke.ps1`：**上板**跑一遍调试口 AT 命令与参数存储检查（L5 硬件在环；默认只读，需要串口，跑前先关掉串口助手）——用法见 [[06-协议格式#怎么验证（AT 命令 + 参数存储）]]
- `sensor-node-fw/QP_INTEGRATION.md`：QP/C 接入点、为 AC6 做的端口改动、CubeMX 再生成流程
- `sensor-node-fw/Qpc/README.md`：QP/C 来源与许可、本仓库对端口的修改记录
