# 4G 业务参数清单

> [!note] 文档定位（2026-09-28 补 frontmatter 时说明）：这是**业务需求稿**，不是已实现清单。
> 第一节列的字段（`angle_*`/`vbat_mv`/`uptime_s`/`reset_reason`/`model`/`sn`）里，
> **只有 `model`/`sn` 已有参数存储**（`SN` 自 2026-09-28 起是设备身份，见 [[06-协议格式#设备标识（deviceId）]]），
> 其余字段**都还没进上报报文**。传感器仍是仿真源（[[09-系统架构]] 第 3 节）。
>
> [!warning] 与平台给的样例**不是同一套物模型**（2026-09-29 发现，待确认）
> 平台方给的下发样例是 `{"deviceId":…,"properties":{"frequencyModulus":4795.6,"temperature":24.1,"stress":-35.8}}`
> —— `frequencyModulus`（频率模数 = 频率²/1000）与 `stress`（应力，MPa）是**振弦式**传感器的量，
> 而本稿写的是**倾角** `angle_x/y/z` + 电池电压 `vbat_mv`。两者不是一回事。
> **报文形状已按平台样例改了**（见 [[08-改动日志]] `#77`），但 `properties` 里的**标识符**还没对齐：
> 除 `temperature` 外都只是占位名。**请平台确认本产品的物模型属性清单**（名字/类型/单位/小数位），
> 拿到后设备侧只改 `modem_component.c` 的 `MODEM_PROP_*` 一处；本稿第一节的字段名也应随之改名。

## 一、设备提供的数据（只读）

| 项目           | 建议字段名                         | 类型 / 单位 | 说明                    |
| ------------ | ----------------------------- | ------- | --------------------- |
| 倾角 X / Y / Z | `angle_x` `angle_y` `angle_z` | 数值，度    | 三轴；小数位待定（见第六节）        |
| 传感器温度        | `sensor_temp`                 | 数值，℃    | SCL3300 芯片内置，供温度补偿与诊断 |
| 电池电压         | `vbat_mv`                     | 整数，mV   |                       |
| 型号 / SN      | `model` `sn`                  | 字符串     |                       |
| 固件版本 / 编译日期  | `fw_ver` `fw_build`           | 字符串     |                       |
| 配置版本号        | `config_version`              | 整数      | 云端据此核对「下发的参数是否真的生效」   |
| 信号质量         | `signal_csq`                  | 整数 0–31 | 99 表示未知               |
| 网络状态         | `net_reg`                     | 枚举      | 已注册 / 未注册             |
| 运行时长 / 复位原因  | `uptime_s` `reset_reason`     | 整数 / 枚举 | 复位原因含上电、看门狗、软复位       |


## 二、可修改的参数

| 项目    | 类型 / 单位        | 谁能改     | 说明                    |
| ----- | -------------- | ------- | --------------------- |
| 工作模式  | 枚举：0 运行 / 1 调试 | 运行（需凭据） | 只有进调试模式，才放开下面标「仅调试」的项 |
| 上报周期  | 整数，秒           | 运行      | 客户端按分钟 / 小时下发与呈现      |
| 上报内容  | 多选             | 运行      | 见第四节                  |
| 上报开关  | 布尔             | 运行      | 临时停报，不必改周期            |
| 设备名   | 字符串            | 仅调试     | 标签类信息                 |
| 安装位置  | 字符串            | 仅调试     | 标签类信息                 |
| 蓝牙名   | 字符串            | 仅调试     | 批量修改用                 |
| 蓝牙 SN | 字符串            | 仅调试     | 批量修改用                 |
| 蓝牙型号  | 字符串            | 仅调试     | 批量修改用                 |


## 三、动作类命令

执行一次，不是参数。

| 项目     | 建议字段名            | 谁能做 | 说明         |
| ------ | ---------------- | --- | ---------- |
| 立即上报一次 | `report_now`     | 运行  | 不必等下一个上报周期 |
| 零点标定   | `calibrate_zero` | 运行  | 把当前姿态设为 0° |
| 自检     | `selftest`       | 运行  |            |
| 重启     | `reboot`         | 运行  |            |


## 四、上报内容（按大类多选）

| 大类     | 含哪些字段                                       | 建议默认 |
| ------ | ------------------------------------------- | ---- |
| 倾角     | `angle_x` `angle_y` `angle_z` `sensor_temp` | 开    |
| 电源     | `vbat_mv`                                   | 开    |
| 设备信息   | 设备信息即可                                      | 开    |
| 网络（可选） | `signal_csq` `cell_tac` `cell_id`           | 开    |

## 五、权限与通用约定

- **权限三级**：任何模式可读 / 运行模式可改 / 仅调试模式可改。
- 进入调试模式需要凭据；建议加超时，自动退回运行模式。
- 上报周期以**秒**为最小单位，客户端限制为整分钟 / 整小时。
- 只读数据既可随周期上报，也可按需查询（全部或单个）。
