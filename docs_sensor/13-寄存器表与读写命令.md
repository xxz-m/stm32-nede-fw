## 一、命令与帧格式

| 命令 | 请求（负载在引号内） | 应答 |
|---|---|---|
| 读 | `AT+READ="<地址>,<地址>,…,<CRC>"` | `+READ:"<地址>,<数据>,…,<CRC>"` |
| 写 | `AT+WRITE="<地址>,<数据>,…,<CRC>"` | `+WRITE:"<地址>,<错误码>,…,<CRC>"` |

- **地址 2 位大写 hex、数据 4 位大写 hex**，宽度固定 → 上位机可以定长解析
- 分隔符只用半角逗号 `,`；**出现空格按格式错处理**（不做“宽容跳过”）
- 应答里**带地址**（自描述）：哪怕请求顺序乱、有重复也能对上号；应答顺序**与请求一致**，重复地址**后写生效**

### 1.1 CRC

| 项 | 规定 |
|---|---|
| 算法 | **Modbus CRC16**：多项式 0x8005（反射实现用 0xA001）、初值 0xFFFF、输出不异或 |
| 覆盖范围 | **引号内的负载全文**（ASCII 字节）；**不含**引号、**不含** `AT+READ=` / `+READ:` 这类前缀 |
| 显示 | 4 位大写 hex，**低字节在前**（与 Modbus 线上顺序一致） |
| 方向 | 双向都带、双向都校验（文档要求上位机也校验应答） |
| 例外 | 协议级错误应答（`ERROR` / `+CME ERROR:n`）**不带 CRC** |

> [!warning] 两种字节序并存，别写反
> **数据字段是“高字节在前”（大端）**，例如 `0032` = 0x0032 = 50；
> **CRC 字段是“低字节在前”**（Modbus 惯例），例如 CRC 值 0xFC65 写成 `65FC`。
> 这跟 Modbus 完全一致：寄存器值大端、CRC 小端。这是最容易写错的一处，文档里每次都给完整示例。

### 1.2 数值语义

- 寄存器里放**原始 16 位值**，**缩放 / 符号 / 单位全部由表定义**（见 §二）
- 上位机负责把原始值换算成工程值：`工程值 = 原始值 × 缩放`
- 有符号量用**二进制补码**（如 −40 → `FFD8`）
- 字符串量（设备名、批次…）占多格、每格 2 字节 ASCII、不足补 `00` —— **本稿暂不分配地址**（见 §六 待定）

## 二、倾角仪寄存器表

地址分区（留空隙，便于以后加）：

| 区段 | 用途 |
|---|---|
| `0x01`–`0x0F` | 配置区：可读写、掉电保持 |
| `0x10`–`0x1F` | 实时测量区：只读 |
| `0x20`–`0x2F` | 设备信息区：只读 |
| `0x30`–`0x3F` | 状态与告警：预留 |
| `0x40`– | 字符串区：待定 |

| 地址     | 名称                | 类型  | 读写  | 缩放      | 单位  | 范围               | 默认  | 掉电  | 权限   |
| ------ | ----------------- | --- | --- | ------- | --- | ---------------- | --- | --- | ---- |
| `0x01` | 上报周期 `transintvl` | u16 | RW  | ×1      | 分钟  | 1–20             | 20  | ✅   | 云端可写 |
| `0x02` | X 阈值 `thr_x`      | s16 | RW  | ÷10     | °   | −900…900（±90.0）  | 待定  | ✅   | 云端可写 |
| `0x03` | Y 阈值 `thr_y`      | s16 | RW  | ÷10     | °   | 同上               | 待定  | ✅   | 云端可写 |
| `0x04` | Z 阈值 `thr_z`      | s16 | RW  | ÷10     | °   | 同上               | 待定  | ✅   | 云端可写 |
| `0x10` | X 倾角 `angle_x`    | s16 | RO  | ÷100    | °   | −18000…18000     | —   | 易失  | 只读   |
| `0x11` | Y 倾角 `angle_y`    | s16 | RO  | ÷100    | °   | 同上               | —   | 易失  | 只读   |
| `0x12` | Z 倾角 `angle_z`    | s16 | RO  | ÷100    | °   | 同上               | —   | 易失  | 只读   |
| `0x13` | 传感器温度             | s16 | RO  | ÷100    | ℃   | —                | —   | 易失  | 只读   |
| `0x20` | 固件版本              | u16 | RO  | 主×100+次 | —   | 如 `0102` = v1.02 | —   | 易失  | 只读   |


## 三、示例帧

> 下列 CRC 均为**实算值**（Modbus CRC16，覆盖引号内负载，低字节在前）。
> 校验方法：把引号内的内容（不含引号）按 ASCII 算 CRC16，取 4 位大写 hex 并按低字节在前排列。

### 例 1：写上报周期 = 5 分钟

```
请求   AT+WRITE="01,0005,65FC"
                    ↑ 0x01 地址、0x0005 = 5 分钟
                    ↑ CRC 覆盖 "01,0005" = 0xFC65 → 低字节在前 = 65FC
应答   +WRITE:"01,00,BF25"
                    ↑ 地址 0x01 → 错误码 00 = 成功
                    ↑ CRC 覆盖 "01,00" = 0x25BF → 低字节在前 = BF25
```

### 例 2：一次写三个阈值（X=5.0°、Y=−4.0°、Z=10.0°）

```
请求   AT+WRITE="02,0032,03,FFD8,04,0064,DB36"
                     ↑ X 阈值：0x0032 = 50 → ÷10 → 5.0°
                        ↑ Y 阈值：0xFFD8 = 补码 −40 → ÷10 → −4.0°
                            ↑ Z 阈值：0x0064 = 100 → ÷10 → 10.0°
                                        ↑ CRC 覆盖 "02,0032,03,FFD8,04,0064" = 0x36DB → DB36
应答   +WRITE:"02,00,03,00,04,00,511B"
                     ↑ 三格全部 00 = 成功
                                    ↑ CRC 覆盖应答负载 = 0x1B51 → 511B
```

同一个请求，若 0x03（Y 阈值）的值超范围，应答会变成：

```
应答   +WRITE:"02,00,03,03,04,00,621B"
                     ↑ 地址 03 的错误码 = 03（值超范围）；02 与 04 仍为 00（**已生效**）
```

### 例 3：读 X / Y / Z 倾角

```
请求   AT+READ="10,11,12,93C8"
                    ↑ 读 0x10 / 0x11 / 0x12 三格
                              ↑ CRC 覆盖 "10,11,12" = 0xC893 → 93C8
应答   +READ:"10,0BB8,11,03E8,12,0064,8A5E"
                    ↑ 0x0BB8 = 3000 → ÷100 → X = 30.00°
                            ↑ 0x03E8 = 1000 → ÷100 → Y = 10.00°
                                    ↑ 0x0064 = 100 → ÷100 → Z = 1.00°
                                                  ↑ CRC 覆盖应答负载 = 0x5E8A → 8A5E
```

**一次读的最大规模**：16 个地址 —— 负载 `10,11,…,20` = 16×2 + 15 个逗号 = 47 字符，
加 `,CRC` 5 字符，再加 `AT+READ="` 9 与收尾 `"` 1，合计 **62**，在上限 64 之内。

（写 6 对同理：负载 6×2 + 6×4 + 11 个逗号 = 47，加 `,CRC` 5、`AT+WRITE="` 10、`"` 1 = **63**，刚好卡满。）

## 四、错误码

### 4.1 逐地址错误码（写在 `+WRITE:` 应答里）

| 码 | 含义 | 触发 |
|---|---|---|
| `00` | 成功 | — |
| `01` | 地址不存在 | 表里没有这个地址 |
| `02` | 地址只读 | 对 `RO` 地址执行写 |
| `03` | 值超范围 | 超出该地址的“范围”列 |
| `04` | 值格式错 | 不是 4 位 hex / 含非法字符 |
| `05` | 该地址仅串口可写 | 云端写了权限受限的地址 |
| `06` | 存储未就绪 / 写入被拒 | EEPROM 忙或参数还未加载完 |
| `07` | 该地址不属于数据区 | 误用了动作或元信息地址 |

### 4.2 帧级错误（整条命令不可信，**不带 CRC**）

| 响应             | 触发                     |
| -------------- | ---------------------- |
| `+CME ERROR:6` | **CRC 校验失败**           |
| `+CME ERROR:2` | 地址个数为 0 / 地址或数据位数不对    |
| `ERROR`        | 总长超限（超过 AT 单行上限）或命令不成形 |
